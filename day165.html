帮助新同事配置开发环境

Setting Up a Development Environment

每天十分钟学习实用的英国职场英语口语。

今天的10句

前6句重点掌握，后4句自然表达；★为优先掌握的3句。

重点掌握 · 6句

1 ★ 高频重点

Can you run the project on your laptop yet?

/kæn juː rʌn ðə ˈprɒdʒekt ɒn jɔː ˈlæptɒp jet/

你现在能在笔记本上运行项目了吗？

run the project＝启动项目运行，而非阅读代码。
2

Not quite; I'm missing a required package.

/nɒt kwaɪt aɪm ˈmɪsɪŋ ə rɪˈkwaɪəd ˈpækɪdʒ/

还不行，我少装了一个必要依赖包。

not quite＝还差一点；required package＝必需软件包。
3 ★ 高频重点

Have you checked the setup instructions?

/hæv juː tʃekt ðə ˈsetʌp ɪnˈstrʌkʃənz/

你看过环境配置说明了吗？

setup instructions＝安装及配置步骤。
4

Yes, but one command fails on Windows.

/jes bət wʌn kəˈmɑːnd feɪlz ɒn ˈwɪndəʊz/

看过，但有条命令在Windows上执行失败。

fails on Windows＝在Windows环境里执行不成功。
5 ★ 高频重点

Could you paste the full error message?

/kʊd juː peɪst ðə fʊl ˈerə ˈmesɪdʒ/

你可以把完整错误信息贴出来吗？

paste＝把复制好的文本粘贴出来。
6

I'll put it in the team chat now.

/aɪl pʊt ɪt ɪn ðə tiːm tʃæt naʊ/

我现在发到团队聊天里。

put it in＝把信息发到某个位置。

自然表达 · 4句

7

Make sure you're using the supported version.

/meɪk ʃɔː jɔː ˈjuːzɪŋ ðə səˈpɔːtɪd ˈvɜːʃən/

确保使用的是受支持的版本。

supported version＝项目明确兼容的版本。
8

The configuration file shouldn't contain passwords.

/ðə kənˌfɪɡəˈreɪʃən faɪl ˈʃʊdnt kənˈteɪn ˈpɑːswɜːdz/

配置文件不应该包含密码。

contain passwords＝把敏感密码直接存入文件。
9

Let's try a clean installation first.

/lets traɪ ə kliːn ˌɪnstəˈleɪʃən fɜːst/

先试一次全新安装吧。

clean installation＝去掉旧安装残留再安装。
10

I'll update the guide with this workaround.

/aɪl ʌpˈdeɪt ðə ɡaɪd wɪð ðɪs ˈwɜːkəraʊnd/

我会把这个临时解决办法补充进指南。

workaround＝绕过当前问题的临时解决方法。
