核对CSV批量导入结果

Validating a CSV Data Import

每天十分钟学习真实英国职场情境的自然口语。

今天的10句

前6句重点掌握，后4句自然表达；★为最重要的3句。

重点掌握 · 6句

1 ★ 高频重点

How many rows did the import process?

/haʊ ˈmeni rəʊz dɪd ði ˈɪmpɔːt ˈprəʊses/

这次导入处理了多少行？

rows＝表格或数据库中的记录行。
2

It processed almost all of them, but some failed.

/ɪt ˈprəʊsest ˈɔːlməʊst ɔːl əv ðəm bət sʌm feɪld/

几乎全部处理了，但有一些失败。

processed＝系统已处理，不代表每条都成功。
3 ★ 高频重点

Can we see which records were rejected?

/kæn wiː siː wɪtʃ ˈrekɔːdz wə rɪˈdʒektɪd/

能查到哪些记录被拒绝了吗？

rejected＝校验或导入时被系统拒绝。
4

Yes, the report lists each row and its error.

/jes ðə rɪˈpɔːt lɪsts iːtʃ rəʊ ənd ɪts ˈerə/

可以，报告列出每行及对应的错误。

lists each row＝逐行列明，而不只显示总数。
5 ★ 高频重点

Did we check for duplicate identifiers?

/dɪd wiː tʃek fə ˈdjuːplɪkət aɪˈdentɪfaɪəz/

我们检查过重复标识符了吗？

duplicate identifiers＝出现了相同唯一标识的记录。
6

Yes, and we kept the original records unchanged.

/jes ənd wiː kept ði əˈrɪdʒənəl ˈrekɔːdz ʌnˈtʃeɪndʒd/

检查了，而且没有改动原始记录。

unchanged＝保持原样，没有被覆盖。

自然表达 · 4句

7

The header names don't match the expected format.

/ðə ˈhedə neɪmz dəʊnt mætʃ ði ɪkˈspektɪd ˈfɔːmæt/

列标题名称与预期格式不匹配。

header names＝CSV第一行的列名。
8

Let's compare the totals before we publish the data.

/lets kəmˈpeə ðə ˈtəʊtəlz bɪˈfɔː wiː ˈpʌblɪʃ ðə ˈdeɪtə/

发布数据前先核对总数吧。

compare the totals＝核对导入前后的数量是否一致。
9

I'll keep a copy of the failed rows for review.

/aɪl kiːp ə ˈkɒpi əv ðə feɪld rəʊz fə rɪˈvjuː/

我会保留失败行的副本以便复查。

for review＝留作后续审查。
10

We shouldn't rerun the whole file without checking.

/wiː ˈʃʊdnt ˌriːˈrʌn ðə həʊl faɪl wɪˈðaʊt ˈtʃekɪŋ/

没确认清楚前不应该重跑整个文件。

the whole file＝整个数据文件，可能导致重复导入。
