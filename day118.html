确认软件版本兼容

Checking Version Compatibility

真实英国出差生活和工作中的自然口语，十分钟掌握重点表达。

10句实用口语BrE/RP IPA逐句解释

今天的10句

前6句重点掌握，后4句自然表达/听懂也很有用。★ 是今天最值得优先记的3句。

重点掌握 · 6 句

1
★ 高频重点

Which version of the library are we using?

/wɪtʃ ˈvɜːʃən ɒvðə ˈlaɪbrəri ɑː wiː ˈjuːzɪŋ/

我们现在使用哪个版本的库？

library＝开发中复用的代码组件
2

The service is still on the previous minor version.

/ðə ˈsɜːvɪs ɪz stɪl ɒnðə ˈpriːvɪəs ˈmaɪnə ˈvɜːʃən/

服务还在用上一个次版本。

minor version＝版本号中通常表示较小更新的一部分
3
★ 高频重点

Does the new client support that version?

/dʌz ðə njuː klaɪənt səpˈɔːt ðæt ˈvɜːʃən/

新客户端兼容这个版本吗？

support＝能够正常配合使用
4

Not fully. One endpoint behaves differently.

/nɒt ˈfʊli wɒn ˈendpɔɪnt bɪhˈeɪvz ˈdɪfrəntli/

不完全兼容，有一个接口行为不同。

endpoint＝API 的一个访问入口
5
★ 高频重点

Can we check the compatibility notes before upgrading?

/kæn wiː tʃek ðə kəmpˌætəbˈɪlɪti nəʊts bɪfˌɔːr ʌpɡrˈeɪdɪŋ/

升级前能先看兼容性说明吗？

compatibility notes＝版本之间能否互通的说明
6

Yes, and we should test the old integration as well.

/jes ænd wiː ʃʊd test ðɪ əʊld ˌɪntɪɡrˈeɪʃən æz wel/

可以，也应该测试旧对接。

as well＝同样也需要

自然表达 / 听懂也很有用 · 4 句

7

I'd rather avoid changing both sides at once.

/aɪd ˈrɑːðər əvˈɔɪd ˈtʃeɪndʒɪŋ bəʊθ saɪdz ətwˈɒns/

我希望避免两边同时改动。

at once＝同时
8

Let's pin the working version for this release.

/lets pɪn ðə ˈwɜːkɪŋ ˈvɜːʃən fɔː ðɪs rɪlˈiːs/

这次发布先锁定已验证可用的版本吧。

pin the version＝固定依赖版本
9

Could you record the supported versions in the README?

/kʊd juː rɪkˈɔːd ðə səpˈɔːtɪd ˈvɜːʃənz ɪnðə ˈriːdmiː/

能在 README 中记录支持的版本吗？

supported versions＝已验证兼容的版本
10

I'll add a test for mixed-version communication.

/aɪl æd ə test fɔː ˈmɪkstvˈɜːʃən kəmjˌuːnɪkˈeɪʃən/

我会添加新旧版本混用时的通信测试。

mixed-version＝多版本同时存在的情况
