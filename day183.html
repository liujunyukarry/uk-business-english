隔离测试数据与真实用户数据

Separating Test Data from Real User Data

每天十分钟学习真实英国职场场景中的实用口语。

今天的10句

前6句重点掌握，后4句自然表达；★为3句高频重点。

重点掌握 · 6句

1 ★ 高频重点

Are we using real customer data in this test?

/ɑː wiː ˈjuːzɪŋ rɪəl ˈkʌstəmə ˈdeɪtə ɪn ðɪs test/

这次测试用了真实客户数据吗？

real customer data＝真实客户信息，通常需要严格保护。
2

No, the test environment uses synthetic records.

/nəʊ ðə test ɪnˈvaɪrənmənt ˈjuːzɪz sɪnˈθetɪk ˈrekɔːdz/

没有，测试环境使用的是模拟记录。

synthetic records＝人工生成、不来自真实客户的记录。
3 ★ 高频重点

Who can access the production database?

/huː kən ˈækses ðə prəˈdʌkʃən ˈdeɪtəbeɪs/

谁可以访问生产数据库？

access作动词＝访问或使用。
4

Only authorised staff with an approved need.

/ˈəʊθəraɪzd stɑːf wɪð ən əˈpruːvd niːd/

只有经过授权且确有需要的员工可以。

authorised＝获得正式许可的。
5 ★ 高频重点

Could we mask sensitive fields before exporting?

/kʊd wiː mɑːsk ˈsensətɪv fiːldz bɪˈfɔː ɪkˈspɔːtɪŋ/

导出前能把敏感字段脱敏吗？

mask＝遮盖或替换敏感信息。
6

Yes, but we'll verify the rules before using them.

/jes bət wiːl ˈverɪfaɪ ðə ruːlz bɪˈfɔː ˈjuːzɪŋ ðəm/

可以，但使用前会先验证脱敏规则。

verify the rules＝实际检查规则是否正确执行。

自然表达 · 4句

7

The sample must still cover unusual input values.

/ðə ˈsɑːmpəl mʌst stɪl ˈkʌvə ʌnˈjuːʒuəl ˈɪnpʊt ˈvæljuːz/

样本仍要覆盖少见的输入值。

unusual input values＝不常见但可能有效的输入。
8

We should remove test accounts after the trial.

/wiː ʃʊd rɪˈmuːv test əˈkaʊnts ˈɑːftə ðə ˈtraɪəl/

试验结束后应该清理测试账号。

trial＝这次有限范围的试验。
9

Please don't copy the dataset to your laptop.

/pliːz dəʊnt ˈkɒpi ðə ˈdeɪtəset tə jɔː ˈlæptɒp/

请不要把数据集拷贝到个人笔记本上。

copy to＝将数据转存到另一设备。
10

I'll document the data source and access controls.

/aɪl ˈdɒkjument ðə ˈdeɪtə sɔːs ənd ˈækses kənˈtrəʊlz/

我会记录数据来源和访问控制。

access controls＝决定谁能读写数据的机制。
