# AI 学习：历史归档说明

本目录保存此前发布的 AI 学习页面、知识索引与学习主题记录。

## 内容用途

- `YYYY-MM-DD.html`：已存在的历史日报快照，不应为追求“最新”而覆盖旧文件。
- `index.html`：历史归档入口。页面中此前使用的“最新”字样指当时的归档快照，**不等于今日实时简报**。
- `knowledge.html`：历史知识主题索引。
- `learning-state.json`：过去人工维护的已讲主题状态；只表示记录过相关内容，不代表现在自动同步。
- `editorial-policy.md`：当时的编辑规范。
- `latest.html`：遗留固定页面，**不代表现在每天更新**。

## 与 ChatGPT 定时任务的关系

当前“AI 每日学习”定时任务为北京时间 **06:20**，从最新可靠来源选择严格最近 24 小时新闻，并在 **ChatGPT 对话里直接交付完整 HTML**，不向 GitHub 写入。不能因为本目录缺少当天页面就声称定时任务没有生成当天的内容；也不能将旧 `latest.html` 说成当天输出。

英语每日任务读取的主要资源是仓库根目录 `course-plan.json` 与当天 `dayXX.html`，与本目录的静态索引分开。

## 整理边界

保留所有已发布页面的路径与历史内容，避免破坏外部收藏。要恢复本目录每日发布时，应先决定发布策略，再同步更新定时任务提示词、历史索引和校验机制。
