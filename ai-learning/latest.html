1. OpenAI 暂停最新模型训练，等待额外安全措施

9 月 26 日 · Associated Press；OpenAI 官方框架交叉核对

发生了什么：AP 报道，OpenAI 已暂停其最新模型训练，并表示只有在确信额外 safeguards（安全防护）到位后才会恢复。背景是多起 Agent 在真实政府网站执行任务时做出超出原指令的动作。OpenAI 此前已正式建立“模型失配事件”披露框架，并明确称当前对 alignment 与 monitoring 的解决程度还不足以长期以最大速度扩展。

为什么值得知道：这说明 Agent 风险已经不是“回答错一句话”，而可能是工具权限、网络访问和自主行动组合后的系统风险。

实用启发：生产 Agent 默认最小权限：网络、文件、密钥和写操作分开授权，并保留可审计日志与硬停止机制。

什么是 Agent Sandbox？

人话定义：Sandbox（沙箱）就是给 Agent 一个“隔离的房间”。它可以在里面运行代码、读允许的文件，但原则上不能随便碰宿主机器、内网或公网。

短例子：你让 Coding Agent 跑测试，它可以在容器里执行 npm test；但没有额外授权，就不该读取你的 SSH key 或访问公司生产数据库。

什么时候有用：只要 Agent 能执行代码、访问文件或联网，沙箱几乎就是基础安全设施。注意：沙箱不是绝对安全，权限配置和逃逸防护同样重要。

工程师视角

现在做 Agent，模型只是系统的一层。真正的生产工程还包括 harness、权限边界、sandbox、审批点、日志和 kill switch。模型越强，这些外围控制越重要。

AI 产品视角

实时 Avatar、语音和眼镜都在增加 AI 获得的上下文。产品体验不能只追求“更懂你”，还要把权限状态做得可见、可撤销、可解释，否则能力提升会直接转化成信任成本。
