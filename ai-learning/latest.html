模型治理 · 重点

1. 微软公布 MAI 模型行为准则草案：模型不得抗拒关停

2026-09-14 · Microsoft AI 官方公告 + Reuters

发生了什么：微软发布 Humanist AI Code of Conduct 初稿，要求未来 MAI 模型接受纠正、不得扩大自身权限或抗拒中断和关停，并禁止隐藏供审计的信息。该文件开放六周征求意见，微软称之后才会用于训练未来模型；它目前是草案，不是已完成部署的产品能力。

为什么值得知道：模型“是否听话”正从抽象价值观变成可测试的产品要求，尤其影响能操作电脑和调用工具的 Agent。

实用启发：为高权限 Agent 写一份可执行的行为规范，并用权限上限、审计日志和外部停止开关落实，而非只靠提示词。

2. Anthropic 推出 Claude for Financial Advisors

2026-09-14 · Anthropic 官方资料 + Reuters

发生了什么：Anthropic 推出面向理财顾问的企业方案，把 Claude 连接到 CRM、托管、投资组合和财富管理软件，用于会前准备、组合复核、跟进和合规检查。官方强调每项动作由顾问批准并保留审计记录；这是行业化企业产品，不是面向所有 Claude 用户的新模型或全面开放功能。

为什么值得知道：AI 产品竞争正在从“聊天框更聪明”转向“能否安全接入现有业务系统并完成整段工作”。

实用启发：做垂直 Agent 时，连接器、审批点和审计证据往往比再写一层通用提示词更有价值。

数据与采购

3. 多家企业据报因数据留存风险限制前沿模型使用

2026-09-14 · Reuters 转述 The Information；相关公司未正式确认

发生了什么：报道称 Palantir 要求不可撤销的“零数据留存”保证，NVIDIA 把 Anthropic 模型限制在较低敏感度任务，Booz Allen 则禁止其用于专有网络安全工作。Anthropic、OpenAI 及相关客户未立即回应，因此这些具体安排应视为可靠媒体报道，而非厂商正式公告。

为什么值得知道：“默认不拿客户数据训练”不等于“完全不保存日志”；两者在企业合规和知识产权风险上差别很大。

实用启发：采购模型时分别核对训练用途、日志保存期、人工访问、删除机制和地区存储，别只看一句“不会训练”。

2026-09-10 公告；2026-09-14 12:00 北京时间生效 · DeepSeek 官方

发生了什么：DeepSeek V4.1‑Flash 已通过 deepseek-flash 提供 API 与多模态能力。官方公告称，从 9 月 14 日 04:00 UTC 起，所有 deepseek-v4-pro 请求会按 V4.1‑Flash 费率路由到它，直到 V4.1‑Pro 发布；旧 Flash 型号也暂时兼容路由。

5. 欧洲央行警告：欧洲需自建算力与“够用”的本地模型

2026-09-14 · Reuters 报道欧洲央行行长讲话

发生了什么：欧洲央行行长拉加德称，欧洲大量依赖海外 AI，一旦访问条件变化，银行、医疗、交通等行业会同时受影响。她主张扩充欧洲数据中心，并发展能在本地基础设施运行、对多数任务“足够好”的模型；她估算快速采用 AI 十年内可把生产率水平提高最多 4%。

为什么值得知道：模型选型不再只是效果和单价，也包含供应连续性、数据主权与退出成本。

实用启发：关键系统应保留第二模型或本地替代路径，并把迁移测试纳入灾备演练。

新手知识点

零数据留存，不等于“不用于训练”

人话定义：“不用于训练”只约束厂商是否拿内容改进模型；零数据留存（ZDR）则要求服务处理后不保存内容或只保留极少必要信息。

短例子：一家 API 可以承诺不训练你的代码，却仍为排障或防滥用保留日志若干天。对普通问答影响有限，对未公开源代码、财务和医疗数据却可能不可接受。

什么时候有用：任何会传入客户资料、商业秘密或受监管数据的产品，都应在架构设计前确认合同与实际日志策略。
