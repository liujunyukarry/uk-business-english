1. Anthropic 首次量化 Claude 参与下一代 AI 研发的程度

9 月 25 日 · Anthropic 官方研究

发生了什么：Anthropic 公布 R&D Automation Index：截至 8 月，Claude 在其测量范围内“主导”约 26% 的 AI 研发工作，超过 90% 达到至少“人机协作”；官方同时强调，Claude 尚未在任何被测子集实现完全自主研发。

实用启发：团队评估 Coding Agent 时，也应记录独立完成比例、人工介入次数和节省时间，而不只看 benchmark。

发生了什么：Google 发布 Gemini 3.8 Live with Live Avatar，把视觉和音频输入、语音回复与低延迟视频形象结合。当前明确可用于 Gemini Enterprise；自定义 Avatar 还需要企业 allowlist，并非所有 Gemini 用户全面开放。

3. Anthropic 用“迷你市场”研究 Agent 之间的交易与博弈

9 月 24 日 · Anthropic Research 官方

发生了什么：Project Swap 让多个 Claude Agent 在实验市场里代表人类交易，观察它们在竞争、协作和信息不完整时会产生什么行为。这是研究实验，不是面向普通用户的新产品。

为什么值得知道：未来系统可能不是一个 Agent 调一堆 API，而是多个拥有不同目标、权限和信息的 Agent 相互作用。

实用启发：多 Agent 测试不能只测单体准确率，还要测冲突、错误传播、串谋和资源竞争。

新手知识点

什么叫 Agentic Coding？

人话定义：不是你问一句、AI 回一段代码，而是你给目标后，AI 能自己读项目、改多个文件、运行工具、发现错误再继续修。

短例子：“给订单系统加退款功能”——Agent 会找接口、改后端和前端、跑测试，再根据报错迭代。

什么时候有用：跨文件、需要多步骤执行和验证的开发任务最能体现它的价值。

工程师视角

Agent 能力越强，评估单位越应该从“单次回答”升级为“完整任务”：成功率、人工接管次数、总 token/时间、测试是否真正通过。

AI 产品视角

个人 Agent 和实时 Avatar 都在争夺更多上下文。用户愿不愿意长期使用，最终很大程度取决于是否清楚知道 AI 看到了什么、记住了什么、准备做什么。
