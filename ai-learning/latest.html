1. Anthropic 把 Claude Chat 与 Cowork 合并，并推出 Docs / Slides

2026-09-16 · Anthropic 官方发布信息 + Reuters

新手知识点

什么是“能力路由 / Tool Routing”？

人话定义：用户只说目标，系统自己判断该用聊天、搜索、代码、文档还是其他工具，而不是让用户先选模式。

短例子：你说“分析这份数据并做成 PPT”，系统可以先读文件、再计算、最后调用幻灯片能力，而你不需要手动切三个页面。

什么时候有用：当一个 AI 产品拥有很多工具时尤其重要。优点是更简单；风险是系统可能选错工具，所以工程上需要权限边界、执行日志和失败回退。

工程师 / AI 产品视角

工程师视角

今天最值得关注的是“统一编排层”：模型只是决策核心，真正稳定的 Agent 还需要工具注册、权限、状态、重试、日志和成本监控。不要把所有逻辑塞进一个超长 Prompt。

AI 产品视角

“让用户选模式”正在逐渐变成过渡设计。成熟产品更可能让用户直接说目标，再由系统自动选择能力；产品经理真正要设计的是何时自动执行、何时必须询问用户。
