1. OpenAI、Anthropic、Google DeepMind 据报已就 AI 安全展开协调

2026-09-15 · Reuters 转述 Bloomberg；三家公司尚未就该报道正式确认

发生了什么：Reuters 报道称，三家竞争对手已讨论数周，希望在不申请反垄断豁免的情况下协调前沿 AI 的安全工作。OpenAI 全球政策负责人 Chris Lehane 表示行业可以在灾难性风险等议题上合作；报道发布时三家公司未作正式回应。

为什么值得知道：当模型越来越能自主调用工具、写代码和操作系统，“安全”正在从各家内部规则变成可能需要跨厂商互通的工程问题。

实用启发：企业不要把安全策略绑死在单一模型上；权限、审计、人工批准和紧急停止最好放在模型之外的统一控制层。

2026-09-15 · Meta 官方 + Reuters

实用启发：设计 AI 产品时，可以把基础智能免费化，把高成本生成、自动化频次、专业 Agent 和业务工具作为付费层，而不是简单按模型名称收费。

3. MediaTek 发布 2nm Dimensity 9600 Pro，把“常驻 Agent”做进手机芯片

2026-09-15 · MediaTek 官方 + Reuters

发生了什么：Dimensity 9600 Pro 采用 2nm 工艺和双 NPU 架构。官方称 NPU 1090 的 LLM prefill 性能较上代提升 51%，token/W 提升 55%，并支持最高 30B 参数模型的复杂端侧应用；另一颗低功耗 NPU 专门承担 always-on AI。

2026-09-15 · Anthropic 官方产品培训资料

发生了什么：Anthropic 在最新企业培训中展示模型默认值、成员级支出可见性、Analytics Chat 的自然语言成本查询，以及 Analytics API 的用量/成本报告。这不是新 Claude 模型发布，而是企业消费计费的治理能力更新。

新手知识点

什么是“端侧 AI / On-device AI”？

人话定义：模型直接在手机、电脑、汽车等设备上运行，而不是把每次请求都发送到云服务器。

短例子：手机上的小模型可以先本地总结通知、识别屏幕内容；只有遇到复杂规划时再调用云端大模型。这样通常更快、更隐私，也能减少云端 token 成本。

什么时候有用：涉及个人数据、需要低延迟、网络不稳定，或每天调用次数极高的功能尤其适合。代价是设备算力、内存和电量有限，所以常见做法不是“全本地”，而是端云协同。

工程师 / AI 产品视角

工程师视角

今天最值得建立的能力不是追一个模型，而是统一的模型网关：把权限、日志、成本、回归测试和模型切换放在应用与模型之间。这样安全策略和供应商变化不会直接冲击业务代码。

AI 产品视角

AI 正同时出现两种分层：云端按智能/用量收费，设备端承担便宜、私密、持续运行的任务。设计功能时先判断“必须上云吗”，再决定模型，而不是反过来。
