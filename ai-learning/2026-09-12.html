新手知识点：Duty of care（注意义务）

人话定义：如果你明知道系统存在某类重大风险，就不能只写一句免责声明，而要采取合理措施降低它。比如一个能执行代码的 Agent 已知可能误操作生产环境，那么权限隔离、测试、审批和回滚就不是“加分项”，而可能逐渐变成应尽责任。

短例子：传统聊天机器人回答错一句，风险通常有限；能调用云账号、数据库或部署系统的 Agent，一次错误动作可能直接造成真实损失，因此工程责任会更重。

什么时候有用：当你设计高权限 Agent、金融/医疗/企业系统或任何能影响真实世界的 AI 功能时。

工程师 / AI 产品视角

工程：把 Agent 的网络出口、代码执行、凭据、文件系统和回滚做成独立安全层，不要只依赖 prompt 约束；同时为真实任务建立可重复的端到端评测。

产品：托管 Agent API 会显著降低开发门槛，但也会把竞争点推向“任务定义、权限设计、可观测性和失败恢复”，而不是谁先接上一个模型。
