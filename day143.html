数据库迁移前确认回退方案

Preparing for a Database Migration

十分钟学会真实英国职场场景中的自然口语。

今天的10句

前6句重点掌握，后4句自然表达；★为今天最值得优先记的3句。

重点掌握 · 6句

1 ★ 高频重点

Have we taken a backup before the migration?

/hæv wiː ˈteɪkən ə ˈbækʌp bɪˈfɔː ðə maɪˈɡreɪʃən/

数据库迁移前我们做备份了吗？

take a backup＝创建备份；migration＝数据库迁移。
2

Yes, and we've checked that it can be restored.

/jes ənd wiːv tʃekt ðət ɪt kən biː rɪˈstɔːd/

做了，我们也检查过备份可以恢复。

be restored＝能从备份恢复，并非仅确认文件存在。
3 ★ 高频重点

Can we run the migration in staging first?

/kæn wiː rʌn ðə maɪˈɡreɪʃən ɪn ˈsteɪdʒɪŋ fɜːst/

可以先在预发布环境执行迁移吗？

staging＝上线前用于验证的预发布环境。
4

We already tested it against a recent data copy.

/wiː ɔːlˈredi ˈtestɪd ɪt əˈɡenst ə ˈriːsənt ˈdeɪtə ˈkɒpi/

我们已经用近期的数据副本测试过了。

against a data copy＝以数据副本作为测试对象，不动正式数据。
5 ★ 高频重点

What happens if the migration fails halfway through?

/wɒt ˈhæpənz ɪf ðə maɪˈɡreɪʃən feɪlz ˌhɑːfweɪ ˈθruː/

如果迁移进行到一半失败会怎样？

halfway through＝进行到一半时。
6

We'll stop the release and follow the rollback plan.

/wiːl stɒp ðə rɪˈliːs ənd ˈfɒləʊ ðə ˈrəʊlbæk plæn/

我们会停止发布并按回退方案处理。

rollback plan＝失败后恢复先前状态的预案。

自然表达 · 4句

7

The script needs to run outside peak hours.

/ðə skrɪpt niːdz tə rʌn ˌaʊtˈsaɪd piːk ˈaʊəz/

脚本需要在高峰时段以外运行。

peak hours＝系统使用量最高的时段。
8

I want to confirm that no records will be skipped.

/aɪ wɒnt tə kənˈfɜːm ðət nəʊ ˈrekɔːdz wɪl biː skɪpt/

我想确认不会漏掉任何记录。

skip records＝处理过程中遗漏数据记录。
9

Could you record the execution time?

/kʊd juː rɪˈkɔːd ði ˌeksɪˈkjuːʃən taɪm/

能记录脚本执行耗时吗？

execution time＝任务实际运行花费的时间。
10

Let's keep the old schema until the checks pass.

/lets kiːp ði əʊld ˈskiːmə ənˈtɪl ðə tʃeks pɑːs/

检查全部通过之前先保留旧表结构。

schema＝数据库结构；until＝直到满足条件为止。
