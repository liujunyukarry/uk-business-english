# 汪汪极速杯 · PAW KART 3D

独立的浏览器 3D 道具赛车游戏。延续《线条小狗 · 云上大冒险 3D》的角色资产，新增赛车、赛道、竞赛规则和界面。原游戏没有被覆盖或修改。

## 内容

- 八位可选角色：小金毛、小白、哆啦 A 梦、马里奥、桃桃兔、薄荷熊、星星队长、泡泡探险家。
- 八人单机比赛（玩家 + 七位 AI），三圈，约 70–100 秒一局。
- 三条赛道，各有自己的时段和氛围：花田晴空环线（晴朗正午）、蜜桃糖果海湾（夕阳海湾）、星光云端公路（霓虹星夜）。
- 道具赛、竞速赛（没有道具，漂移给氮气槽充能，最多存两管）、三站积分杯赛；50cc、100cc、150cc 三档难度。两种比赛都有尾流：紧跟在别的车正后方一小会儿就会被吸着加速。
- 七种道具：蘑菇冲刺、追踪红壳、香蕉、一次性护盾、无敌星星、闪电，以及落后时才会出现的火箭冲刺。两个道具槽；问号箱每排横跨整条赛道、每位车手各算各的、撞上必碎，越落后道具越强。
- 四款车型可选：经典卡丁、闪电 GT、喷射火箭、幻影星舰，各有外形和小幅性能取舍；AI 车手也开各式车型。
- 八位车手各有专属必杀技（元气三连冲、完美漂移、四次元口袋、火球连发、蹦蹦跳、熊抱冲撞、流星雨、泡泡护航），漂移、金币、命中对手为必杀槽充能。
- 蓝 / 橙 / 紫三级漂移加速（松手瞬间提速 + 持续冲刺 + 镜头拉伸），起步加速，金币加速，加速带，连续受击保护。
- 右上角小地图：方格终点线、行进方向、所有车手位置（离你近的描白边），下方全程进度条标出每位车手离终点多远，并显示「距终点 X km」；屏幕下方后方雷达提示 25 米内从后面逼近的车。
- 键盘；手机横屏和竖屏触控：点左半屏左转、右半屏右转，弯道里按住方向自动漂移；自动油门、辅助转向、画质和声音设置。
- Web Audio 原创合成音乐（每条赛道一首，最后一圈提速，另有车库主题）和音效；车手表情（开心、眩晕、专注、冲线欢呼）；本浏览器最佳纪录；失焦自动暂停。
- 画面特效（WebGL）：泛光、调色、暗角和冲刺光晕，漂移轮胎印与烟雾，发光粒子；设备不支持或掉帧时自动关闭，设置里也能手动关。

## 运行

这是无构建步骤的静态站，所有模型和库随站点打包，不依赖公共 CDN。

```sh
python -m http.server 8080 --directory dist
```

打开 http://localhost:8080 。请通过 HTTP 服务打开，直接双击 `index.html` 会受到浏览器模块加载限制。

```sh
npm test            # 96 项：确定性模拟、粒子与轮胎印、构建戳、隐私检查、解压兜底（含 V2 原有 18 项）
npm install         # 首次：安装 playwright-core（只用于浏览器测试）
npm run test:e2e    # 50 项浏览器回归测试，需要本机 Chrome；CHROME_PATH 可指定路径
```

模拟测试覆盖三条赛道 × 三档难度的完整三圈比赛、闭合路径、漂移分级与自动漂移、起步加速、道具与道具箱、受击保护、手动油门、AI 难度差异、运动连续性与 AI 超车。`tests/privacy.test.js` 只用通用规则（邮箱、手机号、密钥、个人路径、个人站点链接、图片元数据）检查本目录不含个人信息。浏览器测试在真实页面里用 Chrome 的触控管线操作按钮（卡键、滑出、多指、取消、暂停、切后台、旋转）并在随机掉帧下测量画面抖动和车辆闪现。大多数用例跑在 CPU 兼容渲染器上；后期特效、轮胎印这三项用 SwiftShader 的 WebGL 跑真实的渲染管线，在只有 CPU 的机器上每帧要一两秒，所以整组测试需要十分钟以上（两核机器上约 11 分钟）。`PAWKART_URL=<地址>` 可以对另一个版本（例如 V2）运行同一组浏览器测试。

修改 `dist/` 里的任何文件后运行 `npm run stamp`：它给所有本地模块和样式表的地址加上内容哈希（例如 `./art.js?v=11982f8f`），避免浏览器在更新后混用缓存里的旧文件；`npm test` 会检查哈希是否最新。暂停菜单和玩法说明底部会显示当前构建号。

`tools/inspect.html` 是开发用的车手/赛车检查页：在 `paw-kart-3d/` 目录起静态服务后打开 `tools/inspect.html?kind=bunny&view=three`（视角 front / side / rear / three / back3 / chase，可加 `&boost=drift3`、`&drift=1&steer=1`、`&mood=happy|hurt|focus|cheer`）。

## 实现与限制

主渲染器是 Three.js / WebGL 2，采用模型、灯光、阴影、骨骼动画、跟随镜头和三维赛道。无 WebGL 2 时使用原项目的 CPU 深度缓冲兼容渲染器，保留真实模型和玩法；兼容模式分辨率、帧率、透明效果和阴影会降低。

后期特效（`dist/fx.js`）：场景先画进一张 4 倍多重采样的半浮点渲染目标，亮部经 5 级降采样和升采样成为泛光，最后一遍合成泛光、色调映射（Khronos PBR Neutral）、调色、暗角和冲刺时的边缘拉伸。设备不能渲染到半浮点目标、或者第一次绘制的头两帧读回来是黑的，就永久退回直接渲染。特效开启时渲染倍率最高 1.5 倍；掉帧时分辨率先降到 1.25 倍，仍掉帧就立即降到 1 倍，并从下一场比赛起关掉特效（比赛中途切换会让所有着色器在同一帧重新编译，见 v2.7.1）。兼容渲染器不使用这条管线。

这是非官方同人风格的可玩网页版，不是任天堂产品，也不是现款《马里奥赛车》的像素级复刻。赛道和音乐原创；没有联网多人、正版角色资产导入、反重力或滑翔系统。驾驶采用沿曲线前进与横向转向的街机模型，适合轻量浏览器游玩。

验收环境与未验证项见 QA.md：真实 iPhone 双指手感、GPU 帧率与发热、扬声器听感尚未在实体设备验证。

## v2.1 修复

- 触控转向重写（`input.js`）：按键状态完全由当前触点推导，每个触摸事件都与浏览器的在屏手指列表核对，丢失的松手事件会在下一次触摸时自愈；手指可从 ‹ 滑到 ›，滑出按钮即释放；道具在触摸瞬间触发。
- 碰撞与 AI：位置修正按步限幅、其余用冲量化解；AI 会选边超车、并排保持间距、贴近时才跟速；随机加速改为看得见的弯道漂移加速。
- 画面：物理步之间插值渲染；追尾镜头锚定赛车并在物理步内平滑；近镜头车辆用有序抖动淡出，取消 V2 的“隐藏后突然出现”。
- 氮气：火焰从模型实测的两个排气口喷出，面向镜头的双层火舌，按来源分色，带点火、光、音效和速度线。
- 车手：赛车加方向盘；两只小狗、桃桃兔、薄荷熊的手握方向盘、坐姿和腿脚；漂移时车身偏航、侧倾、加减速俯仰和碰撞晃动。
- 结算页按钮固定在底部，横屏手机无需滚动即可点到。

Kenney 资产的 CC0 许可不覆盖马里奥、哆啦 A 梦、线条小狗等既有角色形象；整个同人项目尚未完成商业发行授权清理。本次修复未修改马里奥、哆啦 A 梦两个角色的模型。

## v2.2 打磨（参考跑跑卡丁车道具赛与马里奥赛车）

- 操作：手机改为左右半屏转向（原 58 px 小方向键太难按）；弯道里按住方向会自动漂移，松开即加速；大号漂移键与道具框；倒计时、横幅不再挡住触摸；触摸“看门狗”在宿主 App 吞掉松手事件时最多 4 秒内自动释放，真实按住的手指下一次微动即恢复。
- 道具：每排 5 个问号箱横跨赛道、每位车手各自一份（前车吃过你照样能吃）；道具按落后距离加权，新增火箭冲刺（只在远远落后时出现，自动驾驶并撞开挡路的车）；AI 会持有道具一段时间，100cc 下玩家每局大约被击中 2–3 次。
- 漂移加速：三级加速各有瞬间提速（3.5 / 5 / 7 m/s）和更长的冲刺（1.0 / 1.6 / 2.3 s），结束后滑行回落；火花颜色、音效、镜头拉伸、速度线随等级变化；起步加速（完美 / 普通）。
- 反馈：超车时名次跳动加提示音，被超时对手回头偷看；被击中红色闪屏、镜头震动、头顶冒星星；命中对手时车手开心；漂移起跳、加速抬头、撞护栏火花、出界扬尘、冲线彩带；道具箱彩虹变色、被别人吃掉后立即重新长出。
- 角色：两只小狗、桃桃兔、薄荷熊有眨眼、开心（^ ^）、眩晕（× ×）、专注（皱眉 / 眯眼）、冲线举手欢呼；每辆车加了车手颜色的天线小旗和车号牌。马里奥、哆啦 A 梦两个角色的模型仍未修改。
- 场景：渐变天空（星光赛道有星空）、远山层次、沥青路面纹理与白色边线、起点看台与观众、彩旗和气球。
- 音乐：三条赛道各一首原创合成曲（鼓、贝斯、和弦、旋律、琶音），最后一圈提速并有短号角，冲线按名次奏乐，车库有主题音乐。

## v2.3（专属必杀技、漂移有意义、手机全面兼容）

- 必杀技：八位车手各有一个专属必杀技，必杀槽由漂移加速、金币、命中对手、被击中和时间充能，满了点必杀键（键盘 E），带角色色的必杀横幅、专属特效和音效；AI 也会使用（会瞄准你的攻击按难度掷骰决定，不会连续轰炸）。
- 过弯：弯道把车往外推（曲率 × 速度²，有上限），普通转向能过普通弯，急弯全速只靠转向会被甩向外侧并掉速；漂移抓地更好、过弯不掉速、出弯还能加速。模拟中（100cc）全程漂移比只转向快约 11%。
- 手机漂移改成一根手指：进弯按住方向自动开始漂移，一直按住保持，松开即加速；修正了 v2.2 自动漂移方向判断反了的问题（向外打方向才触发），AI 漂移时车头也改为朝向弯心。
- 道具：两个道具槽（跑跑卡丁车式），问号箱撞上必碎（槽满也碎，不会再“穿过去”），吃道具时箱子碎成彩虹碎片、道具框滚动后弹出；星星 / 火箭 / 熊抱撞人时把对方推开，不再互相穿模；红壳近距离追踪更准。
- 手机兼容：按 iPhone 14 Pro Max（灵动岛与底部横条安全区）、16 Pro Max、15、13 mini、SE、Pixel 7、小屏安卓、iPad mini / Air 的竖横屏逐一检查：按钮不进安全区、互不重叠、不小于 44 px；横屏把道具 / 必杀 / 漂移键移到拇指上方，下半屏全是转向区。iOS 16.4 以前没有 DecompressionStream 时改用内置 JS 解压加载模型（iOS 15 的老 iPhone 也能进游戏），Safari 加 -webkit-backdrop-filter。
- 性能：场景合批改为按 90 m 分块的顶点色合批，问号箱和金币改为实例化绘制，赛车小零件不投影：每帧绘制调用从约 900 降到约 410。
- 修复：CPU 兼容渲染器里近镜头车辆随帧时间闪烁（淡出值未保存）。

## v2.4（小地图、醒目的必杀技、竞速赛）

- 小地图移到右上角：方格终点线和行进方向箭头，你是黄色箭头，其他车手是各自颜色的圆点，30 米内的对手描白边；地图下方的全程进度条把所有车手到终点的进度排成一条线，再配一行「距终点 X km / m」。地图按屏幕实际像素绘制（iPhone 3 倍屏也清晰），触摸可穿透，按在地图上照样是右转。
- 后方雷达：25 米内从后面逼近的车，会在车下方对应的左边或右边亮出它颜色的箭头和距离，8 米内闪动提醒；同一侧的两辆车上下错开显示。
- 必杀技更醒目：改成更大的圆形按钮，外圈是车手颜色的充能环；充满后变亮、外圈旋转发光，写着「放必杀！」；刚开始玩的几局，充满时会有气泡箭头指向它。流星雨、熊抱冲撞、火球连发这类攻击必杀充满后，会在要打的车头上和小地图上用红色准星标出目标，按钮角上显示锁定人数；流星雨 / 火球前面没人可打、或四次元口袋时两个道具槽都满，按钮会提示，按了也不放（不会白白浪费）。
- 竞速赛：首页模式改为「道具赛 / ⚡ 竞速赛 / 🏆 杯赛」，选择会被记住。竞速赛没有问号箱、金币和必杀；漂移时和漂移加速时给氮气槽充能，最多存两管，点 N₂O 键（键盘空格）喷射 2.3 秒的蓝色氮气；AI 也会在直道上用氮气。竞速赛的最佳纪录单独保存，结算页显示氮气和尾流次数。
- 尾流（两种模式都有）：紧跟在别的车正后方 3.5–16 米、同一条线上约 1.1 秒，会被吸着加速超过去；吸尾流时屏幕边缘出现风线，并显示充能进度。
- 平衡：竞速赛 150cc 的 AI 比道具赛略慢（道具赛里道具会拖慢领先者，竞速赛没有），模拟中会漂移的玩家平均第 2.8 名；100cc 平均约第 1.2 名。
- 熊抱冲撞锁定前方 60 米内最近的车，一直追到抱住它为止（最多 4.5 秒，追击时至少比目标快 18 m/s，贴到身边就算抱住），目标就算正在加速也跑不掉；前面没人时仍是 3 秒冲刺。
- 同一个物理步里两个加速同时触发（例如 AI 吃到加速带又放道具）只给一次瞬间提速，避免速度突然跳变。
- 竞速赛开局会提示玩法，漂移提示条改为「漂移攒氮气」。

## v2.5（起步加速、帅气加速、集气更快、四款车型）

- 漂移平衡，修复「超长时间漂移攒满气、贴着墙撞也能无脑赢」：
  - 漂移现在会掉速：顺着弯道漂约 2%，在直道上漂约 12%。

## v2.7.1（修复：比赛中突然卡死、卡顿）

v2.7 在 iPhone 上玩时会突然卡住不动，有时一卡一卡。在容器里（没有手机）找到并修掉了下面这些原因：

- **比赛中途切换特效导致整帧停住（主要原因）**：v2.7 掉帧时会在比赛中途自动关掉「画面特效」，再不行就关阴影。这两个开关都会改变场景里每一种材质的着色器，浏览器要在同一帧里把它们全部重新编译。这里的 CPU 渲染实测：关特效那一刻要编译 35 个新着色器，两帧之间隔了 13 秒；手机上会是一到几秒的定格。现在比赛中只「预约」关闭，下一场开始或回到车库时才生效（着色器在倒数时预先编译），当下改为把渲染倍率直接降到 1 倍来减负。比赛中不再编译任何着色器（有自动化测试）。
- **越玩越占内存**：每场比赛的赛道和道具（地面、天空球、拱门、标牌、问号箱、金币等）离开时只释放了一部分；AI 每场随机换车型，每一种新的「车手 + 车型」组合都会新建一辆车并永远缓存。同一条赛道连跑六场，显卡里的几何体从 166 个涨到 822 个，贴图从 27 张涨到 88 张，每场都在涨。手机图形内存用完时，系统会收回 WebGL（画面定住）或直接重新载入页面。现在离开比赛就释放赛道和道具，车辆缓存最多 12 辆（当前比赛用到的车不会被清掉）。同样连跑六场，几何体在 330–470 个之间随缓存里的车型浮动，贴图 48 张，不再一直涨。
- **发热与卡顿**：特效开启时渲染倍率上限从 2 倍降到 1.5 倍。特效第一次绘制时读回像素检查是否黑屏，之后改变尺寸不再回读（回读会让 CPU 等 GPU，造成一次停顿）。粒子、轮胎印和加速光带的着色器也在倒数时预编译（之前第一次出现时才编译，会卡一下）。
- **转场**：圆形转场改为纯淡出。原来的圆形是一个带 220vmax 阴影、放大 42 倍的元素，在 3 倍屏手机上要合成几千像素宽的图层。
- **去掉 iOS 隐藏开关震动**：v2.7 在 iPhone 上靠在比赛中点击一个隐藏的开关控件来触发轻触感，这会在比赛中改变焦点，而且苹果已在 iOS 26.5 封堵。现在只在有振动接口的手机（安卓）上震动，iPhone 上不再显示「震动反馈」设置。
- **保护措施**：
  - 某一帧出错不会再让画面冻结：错误被记录，特效关闭，比赛继续；连续出错约 1.5 秒会暂停并提示重新载入。
  - 系统收回图形资源（WebGL 上下文丢失）时比赛暂停；恢复后本次关闭特效再继续；6 秒内没有恢复就提示重新载入（成绩已保存）。
  - 如果上次比赛进行中页面意外退出（特效开着），下次打开会先关闭特效并提示，可在设置里重新打开。
- **运行诊断**：设置 → 「运行诊断」显示版本、显卡、屏幕与渲染倍率、特效状态、帧率与比赛中最慢一帧、画面中断次数、资源数量和最近的错误，可截图或一键复制发给开发者。只显示在本机，不会上传。
