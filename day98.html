排查API对接问题

Troubleshooting an API

真实英国出差生活和工作中的自然口语，十分钟掌握重点表达。

10句实用口语BrE IPA（待逐句复核）逐句解释

今天的10句

前6句重点掌握，后4句自然表达/听懂也很有用。★ 是今天最值得优先记的3句。

重点掌握 · 6 句

1
★ 高频重点

Are we getting a response from the API at all?

/ɑː wiː ɡˌetɪŋ ə rɪspˈɒns frʌmðɪ ˌeɪpˌiːˈaɪ æt ɔːl/

这个API现在有返回响应吗？

at all＝到底有没有，强调基本情况
2

Yes, but the status code is not what we expect.

/jes bʌt ðə ˈsteɪtəs kəʊd ɪz nɒt wɒt wiː ekspˈekt/

有，但状态码不是预期的。

status code＝表示请求结果的HTTP状态码
3
★ 高频重点

Could you share the request you used for testing?

/kʊd juː ʃeə ðə rɪkwˈest juː juːzd fɔː ˈtestɪŋ/

能分享一下测试时发送的请求吗？

request＝发送到接口的请求数据
4

I'll remove any secrets before sharing it.

/aɪl rɪmˈuːv ˌeni ˈsiːkrəts bɪfˌɔː ˈʃeərɪŋ ɪt/

分享前我会去掉敏感密钥。

secrets＝令牌、密码等敏感凭证
5
★ 高频重点

Does the issue happen in both test and production?

/dʌz ðɪ ˈɪʃuː ˈhæpən ɪn bəʊθ test ænd prədˈʌkʃən/

测试环境和生产环境都会发生吗？

production＝面向真实业务运行的环境
6

No, we've only seen it in the test environment.

/nəʊ wiːv ˈəʊnli siːn ɪt ɪnðə test envˈaɪrənmənt/

没有，目前只在测试环境出现。

only seen＝观察范围仅限于

自然表达 / 听懂也很有用 · 4 句

7

Let's compare the configuration on both sides.

/lets kəmpˈeə ðə kənfˌɪɡjərˈeɪʃən ɒn bəʊθ saɪdz/

我们比较一下双方的配置。

on both sides＝通信或集成的双方
8

We should check the timeout before changing the retry logic.

/wiː ʃʊd tʃek ðə ˈtaɪmaʊt bɪfˌɔː ˈtʃeɪndʒɪŋ ðə ˈriːtraɪ ˈlɒdʒɪk/

改重试逻辑前应先查超时设置。

timeout＝允许等待响应的时间上限
9

Can we capture one failing example with a timestamp?

/kæn wiː ˈkæptʃə wɒn ˈfeɪlɪŋ eɡzˈɑːmpəl wɪð ə ˈtaɪmstæmp/

能记录一个带时间戳的失败样本吗？

timestamp＝事件发生的具体时间
10

I'll document the fix once the integration passes.

/aɪl ˈdɒkjuːmənt ðə fɪks wɒns ðɪ ˌɪntɪɡrˈeɪʃən ˈpɑːsɪz/

集成测试通过后我会记录修复方法。

document the fix＝将解决方法写入文档
