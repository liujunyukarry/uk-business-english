制定备份恢复演练计划

Planning a Backup Restore Drill

英国出差日常与工作场景，十分钟练习真实口语。

今天的10句

前6句重点掌握，后4句自然表达；★标出3句优先掌握的重点。

重点掌握 · 6句

1 ★ 高频重点

When did we last test a full restore?

/wen dɪd wiː lɑːst test ə fʊl rɪˈstɔː/

上次测试完整恢复是什么时候？

full restore＝从备份完整恢复系统或数据。
2

It was several months ago, so we're overdue.

/ɪt wəz ˈsevrəl mʌnθs əˈɡəʊ səʊ wɪər ˌəʊvəˈdjuː/

是几个月前，已经该再做一次了。

overdue＝超过应执行的时间。
3 ★ 高频重点

Can we run the exercise without affecting production?

/kæn wiː rʌn ði ˈeksəsaɪz wɪˈðaʊt əˈfektɪŋ prəˈdʌkʃən/

能在不影响生产的情况下做演练吗？

exercise＝这里指系统演练，不是体育锻炼。
4

Yes, we'll use an isolated environment.

/jes wiːl juːz ən ˈaɪsəleɪtɪd ɪnˈvaɪrənmənt/

可以，我们会使用隔离环境。

isolated environment＝与生产系统隔离的环境。
5 ★ 高频重点

What should we measure during the restore?

/wɒt ʃʊd wiː ˈmeʒə ˈdjʊərɪŋ ðə rɪˈstɔː/

恢复过程中需要测哪些指标？

measure＝记录可比较的数值。
6

Let's track the time and check data integrity.

/lets træk ðə taɪm ənd tʃek ˈdeɪtə ɪnˈteɡrəti/

记录耗时并检查数据完整性吧。

data integrity＝数据未被损坏或错误修改。

自然表达 · 4句

7

The backup is only useful if we can restore it.

/ðə ˈbækʌp ɪz ˈəʊnli ˈjuːsfəl ɪf wiː kən rɪˈstɔːr ɪt/

能成功恢复的备份才真正有用。

only ... if ...＝强调必要条件。
8

We should document every step of the procedure.

/wiː ʃʊd ˈdɒkjument ˈevri step əv ðə prəˈsiːdʒə/

应该记录恢复流程的每一步。

procedure＝标准操作流程。
9

I'll ask another engineer to verify the results.

/aɪl ɑːsk əˈnʌðər ˌendʒɪˈnɪə tə ˈverɪfaɪ ðə rɪˈzʌlts/

我会请另一位工程师核实结果。

verify the results＝独立检查结果是否正确。
10

Let's review any gaps after the drill.

/lets rɪˈvjuː ˈeni ɡæps ˈɑːftə ðə drɪl/

演练结束后复盘遗漏的环节吧。

gaps＝流程或能力上的不足。
