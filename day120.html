讲解系统架构图

Walking Through a Diagram

真实英国出差生活和工作中的自然口语，十分钟掌握重点表达。

10句实用口语BrE/RP IPA逐句解释

今天的10句

前6句重点掌握，后4句自然表达/听懂也很有用。★ 是今天最值得优先记的3句。

重点掌握 · 6 句

1
★ 高频重点

Could you walk us through the architecture diagram?

/kʊd juː wɔːk ʌs θruː ðɪ ˈɑːkɪtˌektʃə ˈdaɪəɡrˌæm/

能带大家看一下系统架构图吗？

walk through＝按顺序讲解
2

Sure. I'll start with the main request flow.

/ʃɔː aɪl stɑːt wɪððə meɪn rɪkwˈest fləʊ/

可以，我先从主要请求流程讲起。

request flow＝请求在组件之间流转的路径
3
★ 高频重点

Where does the user request enter the system?

/weə dʌz ðə ˈjuːzə rɪkwˈest ˈentə ðə ˈsɪstəm/

用户请求从哪里进入系统？

enter the system＝进入系统的入口
4

It first reaches the gateway, which routes it to a service.

/ɪt fɜːst ˈriːtʃɪz ðə ˈɡeɪtweɪ wɪtʃ ruːts ɪt tʊ ə ˈsɜːvɪs/

首先到网关，再由网关转发到服务。

gateway＝统一接收和转发请求的入口
5
★ 高频重点

What happens if that service is unavailable?

/wɒt ˈhæpənz ɪf ðæt ˈsɜːvɪs ɪz ʌnəvˈeɪləbəl/

如果那个服务不可用会怎样？

unavailable＝无法正常提供服务
6

The gateway returns an error; we don't retry indefinitely.

/ðə ˈɡeɪtweɪ rɪtˈɜːnz ən ˈerə wiː dəʊnt ˈriːtraɪ ɪndˈefɪnətli/

网关返回错误，我们不会无限重试。

indefinitely＝没有终止条件地持续

自然表达 / 听懂也很有用 · 4 句

7

Let's trace one request from start to finish.

/lets treɪs wɒn rɪkwˈest frɒm stɑːt tə ˈfɪnɪʃ/

我们从头到尾跟踪一个请求吧。

trace＝沿流程逐步追踪
8

I'd like to understand where the state is stored.

/aɪd laɪk tʊ ˌʌndəstˈænd weə ðə steɪt ɪz stɔːd/

我想弄清楚状态存在哪里。

state＝系统需要保留的运行信息
9

Could you mark the external dependencies on the diagram?

/kʊd juː mɑːk ðɪ ekstˈɜːnəl dɪpˈendənsiz ɒnðə ˈdaɪəɡrˌæm/

能在图上标出外部依赖吗？

external dependencies＝依赖的外部系统或服务
10

I'll update the drawing after we confirm the data flow.

/aɪl ʌpdˈeɪt ðə ˈdrɔːrɪŋ ˈɑːftə wiː kənfˈɜːm ðə ˈdeɪtə fləʊ/

数据流确认后我会更新这张图。

data flow＝数据如何移动和处理
