核对API分页查询是否遗漏记录

Checking API Pagination

每日十分钟，学习真实英国工作情境的自然英语口语。

今天的10句

前6句重点掌握，后4句自然表达；★为3句重点。

重点掌握 · 6句

1 ★ 高频重点

Are we getting every page of the results?

/ɑː wiː ˈɡetɪŋ ˈevri peɪdʒ əv ðə rɪˈzʌlts/

我们把所有分页结果都取到了吗？

page of results＝接口分批返回的一页数据。
2

Not yet. The client stops after the first page.

/nɒt jet ðə ˈklaɪənt stɒps ˈɑːftə ðə fɜːst peɪdʒ/

还没有。客户端只取了第一页就停了。

stops after＝完成某步后不再继续。
3 ★ 高频重点

Does the response include a next-page token?

/dʌz ðə rɪˈspɒns ɪnˈkluːd ə nekst peɪdʒ ˈtəʊkən/

响应里有下一页令牌吗？

next-page token＝用于请求后续页面的标记。
4

Yes, we need to pass it in the following request.

/jes wiː niːd tə pɑːs ɪt ɪn ðə ˈfɒləʊɪŋ rɪˈkwest/

有，需要在下一次请求里传入它。

pass it＝作为参数传递。
5 ★ 高频重点

How do we know when to stop fetching?

/haʊ duː wiː nəʊ wen tə stɒp ˈfetʃɪŋ/

怎样判断什么时候停止获取？

fetching＝从服务器继续拉取数据。
6

Stop when the server returns no next-page token.

/stɒp wen ðə ˈsɜːvə rɪˈtɜːnz nəʊ nekst peɪdʒ ˈtəʊkən/

服务器不再返回下一页令牌时就停止。

returns no ... token＝不再提供后续页的指示。

自然表达 · 4句

7

We should check for duplicates across pages.

/wiː ʃʊd tʃek fə ˈdjuːplɪkəts əˈkrɒs ˈpeɪdʒɪz/

还应检查不同页面之间是否重复。

across pages＝跨不同分页结果。
8

The order may change while new records arrive.

/ði ˈɔːdə meɪ tʃeɪndʒ waɪl njuː ˈrekɔːdz əˈraɪv/

新记录进来时，排序可能改变。

while＝在另一个动作发生的同时。
9

Let's test with a dataset larger than one page.

/lets test wɪð ə ˈdeɪtəset ˈlɑːdʒə ðən wʌn peɪdʒ/

用超过一页的数据集测试一下吧。

larger than one page＝确保确实触发分页。
10

I'll compare the total against the source count.

/aɪl kəmˈpeə ðə ˈtəʊtl əˈɡenst ðə sɔːs kaʊnt/

我会拿总数和源数据条数核对。

source count＝原始数据源中的总记录数。
