英国常见说法 / 礼貌提醒

1. acceptance standard
表示双方认可的验收标准。
2. pass inspection
表示通过检验。
3. shown on the drawing
工程语境中 drawing 通常指技术图纸。

常见易错点

❌ Every batch must pass the inspect.
✅ Every batch must pass the inspection.
inspect 是动词，inspection 是名词。

❌ How do you measure about this?
✅ How do you measure this characteristic?
measure 后直接接测量对象。
